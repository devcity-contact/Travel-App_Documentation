# Editing these docs (team only)

- The pages are Markdown files in `docs/`. Edit, commit, push.
- New page: add the file to `docs/` and one line under `nav:` in `mkdocs.yml`.
- Colours and header style: `docs/stylesheets/brand.css`.
- The website is built with [MkDocs Material](https://squidfunk.github.io/mkdocs-material/) (`requirements.txt`). Run `mkdocs build --strict` before pushing to catch broken links.
- Funding application notes: [APPLYING.md](APPLYING.md).
