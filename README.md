## The idea

Travellers type **From** and **To**. We show real local experiences **along the road they're already travelling**, in the order they'll pass them. They book in a minute with a small deposit, get a ticket that works with no signal, and pay the host the rest on the day.

| | |
| --- | --- |
| **Problem** | Tourists drive past amazing local experiences every day and never know they're there. Booking sites only show city tours, and maps don't sell anything. |
| **Solution** | Experiences in road order, with detour times, booked and ticketed in one place. Built for weak signal. |
| **Business model** | Travellers pay a **15% deposit** online (our revenue). Hosts get the other **85% in cash** on the day. Hosts pay nothing upfront. |
| **Market** | Sri Lanka welcomed a record **2.36 million** visitors in 2025, and tourism earned about **US$ 3.2 billion**. Every new country is added as data, not new code. |
| **Status** | Core product built: route search on real roads, booking, deposits, offline tickets, reviews, host tools, staff portal. **Launching soon.** |

## Our promises

- **Experiences only.** No hotels, restaurants or vehicle bookings.
- **One fair price for everyone.** No "tourist price".
- **Tickets work offline.**
- **Hosts keep their money.** We never hold it.
- **Every country is data.** Same platform, new market.
