## The product in 30 seconds

| | |
| --- | --- |
| **Problem** | Tourists drive past amazing local experiences every day and never know they're there. Booking tools only show big cities and big tours. |
| **Answer** | Type From and To. We show real local experiences **along your road**, in the order you'll pass them. Book in a minute. Ticket works offline. |
| **Who pays** | The traveller pays a **15% deposit** online. That's our income. The other 85% goes straight to the host on the day. |
| **Why now** | Sri Lanka had a record **2.36 million** visitors in 2025, but spend per visitor **fell**. Local experiences help visitors spend more, and help it reach villages. |
| **Why us** | Built for the road, for weak signal, and for hosts who aren't online. One fair price for everyone. |

## Our rules (never change)

- ✅ Experiences only. ❌ No hotels, restaurants or vehicle bookings.
- ✅ One fixed price for everyone. ❌ No "foreigner price".
- ✅ Tickets work offline.
- ✅ New countries are added as data, not new code.
- ✅ We never hold a host's money (in the first version).
